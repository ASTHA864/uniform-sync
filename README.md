# UniformSync

UniformSync is a full-stack MERN application designed to manage school uniform inventory, schools, and sales operations efficiently.

## Features

* JWT Authentication
* Role-Based Authorization
* School Management
* Uniform Inventory Management
* Sales Management
* Automatic Stock Updates
* Dashboard Analytics
* Revenue Tracking
* Profit Tracking
* Responsive UI

## Tech Stack

### Frontend

* React.js
* Tailwind CSS
* Axios
* React Router

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT Authentication

## Modules

### Schools

* Add School
* View Schools

### Uniforms

* Add Uniform
* View Uniforms
* Manage Stock

### Sales

* Create Sale
* View Sales
* Auto Stock Reduction

### Dashboard

* Total Schools
* Total Uniforms
* Total Sales
* Total Revenue
* Profit Analytics

## Installation

### Backend

npm install

npm run dev

### Frontend

npm install

npm run dev
